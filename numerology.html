🔢 5. NUMEROLOGY AND PYTHAGOREAN PSYCHOMATRIX

Source data: birth date DD.MM.YYYY. Record all digits in sequence (without dots). Example: 24.03.1995 → 24031995. Zero in day/month (e.g. 08.05) is recorded as 0, but when calculating RC3, zero is NOT counted as first digit of day — for days 1–9 use the number itself (e.g. for 08 use 8).

Life Path Number (LPN): sum of ALL digits of birth date. If result is 11, 22, 33 — these are master numbers, DO NOT reduce. For others: sum digits of result until single digit (1–9). Example: 24.03.1995 → 2+4+0+3+1+9+9+5 = 33 → 3+3 = 6. LPN = 33/6 (master number 33, root 6).

Working Numbers (classical psychomatrix):

  • WN1 = sum of all digits of birth date (day+month+year) = Life Path Number BEFORE reduction (if master number — keep it).
  • WN2 = sum of digits of WN1. If WN1 is master number (11,22,33), WN2 = sum of its digits (2, 4, 6 respectively).
  • WN3 = WN1 − 2 × D, where D:
    • If birth day 1–9 (including 01–09): D = numerical value of day (1, 2, ... 9). For 08: D = 8.
    • If birth day 10–31: D = first digit of number (for 24: D = 2, for 15: D = 1).
  • WN4 = sum of digits of WN3.

Check: all intermediate results must be positive. If WN3 is negative — check: for days 1–9 use D = day (not 0).

3×3 Matrix: count each digit (1 to 9) in all numbers: birth date (DDMMYYYY), WN1, WN2, WN3, WN4. Zero (0) is NOT counted in matrix (not written). Fill cells:

[1, 2, 3]
[4, 5, 6]
[7, 8, 9]

If digit is absent — cell is empty (or 0). If digit repeats — write it as many times as it appears (e.g. three 1s → 111).

Tarot Arcana (personality): sum of digits of birth date (like LPN). If result > 22, repeatedly sum digits of result until you get number 1–22. 22 = Fool. This is personality Arcana.

Tarot Arcana (destiny): sum of digits of birth date + sum of digits of birth year. Reduce by same rule (to 1–22).

Interpretation of digits in matrix (psychomatrix):

  • 1 — character, will, ego-strength (Jung: will as function of consciousness)
  • 2 — energy, empathy, feminine principle, attachment
  • 3 — creativity, structure, order, separation
  • 4 — health, physicality, muladhara, basic safety

📊 6. BIORHYTHMS

Formula: B(t) = sin(2π × N / T), where:

  • N — number of days lived from birth date to current date (request date). Calculate accounting for leap years (leap year — divisible by 4, except centuries not divisible by 400).
  • T = 23 (physical), 28 (emotional), 33 (intellectual).

Calculate B(t) for current date (round to hundredths). Range: from −1 (minimum) to +1 (maximum).

Critical days: when B(t) crosses 0 (sin = 0). This occurs when N = k × T, where k is integer. Find nearest critical dates within ±14 days from current: date = birth date + k×T days. Indicate date and biorhythm type.

Interpretation: B(t) > 0.5 — high level; 0 to 0.5 — rise; −0.5 to 0 — decline; < −0.5 — low level. On critical day (≈0) — increased fatigue, risk of errors, avoid important decisions.
